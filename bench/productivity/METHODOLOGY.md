# Engineering Productivity Benchmark — methodology

Tool: `python -m genesis_rt.cli bench [--tasks ...] [--out DIR]`
(harness: `host/genesis_rt/bench_productivity.py`).

## What is measured

Six concrete engineering tasks run through two lanes:

| Task | Genesis lane (real CLI) | Reference lane (synthetic) |
|---|---|---|
| `validate` | `validate IR` | `bench_ref/check_limits.py IR` (naive checker) |
| `generate` | `generate IR --out` | `bench_ref/render_guard.py` + `cc -fsyntax-only` |
| `campaign` | `faults IR` (8 scenarios, oracles) | 8× `simulate IR --scenario` (no oracles) |
| `evidence` | `demo` + `scripts/replay.py` (bound verdict) | `faults` + `bench_ref/collect_package.py` (no verdict) |
| `compare` | `compare runA runB` | `git diff --no-index --stat runA runB` |
| `regression` | `faults` before + after | 16× `simulate` before + after |

Reference workflows in `scripts/bench_ref/` are SYNTHETIC stand-ins
for manual developer practice, labeled as such in every file header.
Manual steps (eyeballing outputs, hand-writing summaries, interpreting
diffs) are counted and reported — never performed by the harness, and
their absence (e.g. missing `CHECKS.md`) is reported, never stubbed.

Per task and lane the harness records: command count, wall time,
exit codes, artifact manifests (path/bytes/sha256), and a semantic
summary. Each task also injects one fault case and records whether
each lane detects it. The genesis lane is re-run and its semantic
summaries compared (`reproducible`).

## What is NOT claimed

- No human labor savings are estimated. Wall time is machine time on
  the recording host, labeled with platform/Python/CPU count.
- No external pilot was conducted.
- Wall times are not comparable across machines; command counts,
  manual steps, fault detection and reproducibility are.

## Reproduce

```sh
PYTHONPATH=host python -m genesis_rt.cli bench --out bench/productivity/last-run
```

Expected (2026-11-05, Windows 10, CPython 3.14, 16 CPUs):

- 8 genesis commands vs 30 reference commands + 10 manual steps.
- Injected faults: genesis 5/5, reference 2/5.
- Genesis lane reproducible: True.

Raw data: `REPORT.json` in this directory (regenerated by the
command above; the committed copy is the latest recorded run).
