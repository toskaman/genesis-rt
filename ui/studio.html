GENESIS RT Studio — specify → compile → run → break → prove

Static page, no build step, no network. Open real artifacts (IR JSON, generated C, passport JSON) and every check below is recomputed live in your browser. Nothing here executes a pipeline: the Run tab gives you the exact commands, and you drop the fresh outputs back here.

Machine intent

Open a Machine IR JSON file (e.g. examples/amr-demo/machine-ir.json).

Generated source

Open generated files (genesis_config_gen.h, genesis_machine_gen.c, …). Provenance headers are pinned against the loaded IR.

Digital twin replay

Load a passport in the Passport tab, then pick a scenario in the Lab tab to replay its trace here.

Failure lab

Load a passport in the Passport tab to list its scenarios, seeds and oracle checks.

Proof passport

Open a passport.json. The hash chain is re-verified live; a stored PASS is shown only when valid.

Broken vs fixed

Load two passports (A = before, B = after). Both chains are re-verified; the delta table appears only when both are valid.

Run the pipeline

Copy-paste on your machine (repo root). Outputs land in artifacts/; drop them into the tabs above.

PYTHONPATH=host python -m genesis_rt.cli validate examples/amr-demo/machine-ir.json
PYTHONPATH=host python -m genesis_rt.cli generate examples/amr-demo/machine-ir.json --out /tmp/gen
PYTHONPATH=host python -m genesis_rt.cli faults examples/amr-demo/machine-ir.json
python -m pytest tests/ -q
PYTHONPATH=host python scripts/run_verified_demo.py

QNX target path (needs SDK + QEMU image):

make -C /tmp/gen -f genesis_build_gen.mk qnx
python scripts/qnx_target.py boot ~/qnx800/images/qemu/qemu --accel tcg --cpu max --ssh-port 2222
python scripts/qnx_target.py put /tmp/gen/genesis_* --dest /tmp/genesis
python scripts/qnx_target.py verify --out artifacts/qemu-boot/target-record.json
