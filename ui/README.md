# UI (MVP)

`dashboard.html` is a static, dependency-free Proof Passport inspector:
open it in a browser, load a `passport.json`, and every verdict is
computed live from that file. No build step, no network calls.

The full six-panel workspace (Intent / Source / Runtime / Twin /
Failure Lab / Passport) from the master plan is roadmap after the
verified demo is solid; this page covers the "prove" step honestly
today without mockup risk.
