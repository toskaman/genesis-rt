# P1 #11 (host slice) Implementation Plan: machine-specific C generation from IR v2

> **For agentic workers:** implement task-by-task, keep the suite green.

**Goal:** Generate a machine-specific C module from IR v2 with structural
differences per machine, proven by snapshot tests, host behavioral tests,
and a 0-warning `qcc` compile.

**Architecture:** New `host/genesis_rt/codegen_v2.py` (v1 `codegen.py`
untouched). String-Template rendering like v1 (no new deps). Generated
`genesis_machine_gen.{h,c}` is self-contained C99, QNX-agnostic, with
generated `switch` logic (not only tables). C-identifier collisions fail
loud. Guard call-site explicitly deferred until P0 #4 on-target proof
lands (no behavior change, no parity risk now).

**Tech Stack:** Python stdlib, C99, host cc + qcc, pytest.
