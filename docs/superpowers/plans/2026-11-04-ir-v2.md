# IR v2 Implementation Plan

> **For agentic workers:** implement task-by-task, keep the suite green.

**Goal:** Ship Machine IR v2 (strict schema + semantic validation + deterministic v1 migration + tests + examples + docs).

**Architecture:** Python validator is the source of truth (`host/genesis_rt/ir_v2.py`, mirrors `ir.py` fail-closed style); JSON Schema file is a secondary artifact for editors/jury; migration is a pure tagged function.

**Tech Stack:** Python stdlib only, pytest, JSON Schema draft-07 (doc only).

### Task 4: Unit tests — validation

**Files:**
- Create: `tests/unit/test_ir_v2.py`

- [ ] Step 1: Valid-doc test (load `examples/amr-demo/machine-ir-v2.json`).
- [ ] Step 2: Rejection tests, one per rule (each asserts `IRValidationError`):
      wrong schema_version, unknown top-level key, unknown machine kind /
      target / arch, empty actuators, duplicate ids (intra-list + global
      actuator/sensor overlap), bad unit for type, bounds min>=max,
      rate_limit<=0, freshness<=0, bad range, period<=0, deadline<=0,
      non-positive speed limits, unknown scheduling policy, priority out of
      1..255, guarded_state_transitions!=true, zero/two initial states, no
      safe state, transition to unknown state, self-transition, unknown event,
      duplicate transition, command to unknown actuator, deadline<=0, empty
      fields, unknown field unit, bad field bounds, telemetry to unknown
      source / duplicate id / rate out of (0,1000], empty safety_contracts,
      unknown if/then, empty fault_responses, unknown fault, unknown
      enter_state, non-safe enter_state, unknown action, empty scenarios,
      requirement to unknown scenario, claim>256 chars, bad dt/duration/seed.
- [ ] Step 3: Run: `python -m pytest tests/unit/test_ir_v2.py -q` → all pass.
