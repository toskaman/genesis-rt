# P1 #12 Slice A Implementation Plan: BeltSim + jam

> **For agentic workers:** implement task-by-task, keep the suite green.

**Goal:** Belt physics + jam scenario with observed-behavior oracle, conveyor
IR lists updated, AMR outputs byte-identical.

by kind; trace/stats via `snapshot()`/`final_stats()`; oracles consume
the same generic keys plus belt keys.

### Task 1: BeltSim + protocol

**Files:**
- Modify: `host/genesis_rt/simulator.py`

- [ ] Step 1: Add `snapshot()`/`final_stats()` to `DiffDriveSim`
      returning exactly today's trace/stat keys (`x,y,theta`,
      `final_x,final_y,collision,wall_hit`).
- [ ] Step 2: Add `BeltSim` (`BeltConfig(dt)`): `position_m`,
      `speed_mps`, `jammed`; `apply(v,w)` ignores `w`, integrates

      decays `*=0.5` per tick, position frozen); `stopped()` sets
      `speed = 0`; `set_jam(bool)`; `snapshot()` →
      `{position,speed,jammed}`; `final_stats()` →
      `{final_position,final_speed}` (+ `collision: False`,
      `wall_hit: False` constants for oracle reuse).
- [ ] Step 3: Unit test `tests/unit/test_belt_sim.py`: integrate,
      ignore-w, jam freeze + decay, no creep, stopped, determinism.
