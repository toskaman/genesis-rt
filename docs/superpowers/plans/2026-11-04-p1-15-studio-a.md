# P1 #15 Slice A Implementation Plan: Studio shell + traceability

> **For agentic workers:** implement task-by-task, keep the suite green.

**Goal:** `ui/studio.html` — six-tab static workspace loading real
artifacts (IR, generated C, passport, traces), verdicts recomputed
live, cross-linked. Inspector core untouched.

**Inputs (all loaded from disk by the user, never fetched):**
- Machine IR JSON (`examples/*/machine-ir.json` shape).
- Generated C dir listing pasted or individual `.h/.c` files.
- Passport JSON (`artifacts/runs/<id>/passport.json` or sample).
- Trace events come from passport `scenario:*` chain bodies
  (`trace.events` or `events_head`+`events_tail`; `x/y/theta` or
  `position/speed/jammed` per tick).
