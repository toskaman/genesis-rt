# P1 #15 design: GENESIS Studio (six-panel workspace)

## Intent

Master-plan UX standard as an honest static workspace: specify ->
compile -> simulate -> break -> fix -> prove, where every panel loads
REAL artifacts from disk and every verdict is recomputed live. No
mock execution, no hard-coded green: the page never claims a run it
did not verify itself.

## Decomposition (ship in slices, suite green at each)

- **Slice A: workspace shell + traceability.** Tab shell around the
  existing passport inspector (keep `dashboard.html` core untouched):
  Intent (load + pretty-print Machine IR, schema/validator summary via
  loaded `validate` transcript), Source (load generated C + build
  record, hash-pinned to the IR sha), Twin (load a faultlab trace JSON,
  2D canvas replay of x/y or belt position), Failure Lab (scenario
  table from the passport chain, seed + oracle per row), Passport
  (existing inspector), Run (exact copy-paste commands + drop fresh
  artifacts here). Cross-links: scenario row -> trace events ->
  source line mentions.
- **Slice B: diff view.** Load two passports (broken vs fixed),
  side-by-side check table + verdict delta. Backs the §7
  break-then-fix story without new backend.

## Contracts

- Static, dependency-free, no network (same as today): one new
  `ui/studio.html` (+ shared JS extracted, not duplicated).
- Trace JSON shape: reuse the passport `scenario:*` chain `trace`
  records (slim) — no new file format; document the loader input.
- JS verification core stays pure + node-tested
  (`tests/ui/test_dashboard_verify.py` extended, same runner).
- Numbers/canonical-form caveat from the inspector applies to every
  panel that re-hashes.

## Self-review

- No placeholders; panels, inputs, and test runner fixed above.
- Consistent: additive file, inspector core untouched, no backend.
- Scope: A then B; video/Devpost explicitly excluded (user-gated).
- Risk: trace replay needs the slim-trace schema pinned — read
  `evidence._slim_trace` before slice A layout.
