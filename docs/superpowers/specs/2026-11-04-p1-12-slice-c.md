# P1 #12 design slice C: belt on QNX (target proof)

Follows slices A (host BeltSim + jam) and B (guard estop). Goal: prove
on the real QNX 8.0/QEMU target that the conveyor is a genuinely
distinct machine: belt kinematics end-to-end plus a guard-level estop
denial observed natively.

## Scope (ship as one slice, verify 10/10 on target)

- **Belt device model (C):** `genesis_belt_state_t` in
  `target/qnx8/common/device_model.{h,c}` — position/speed, arrival-dt
  integration with the previous setpoint (same convention as the pose
  model), dt clamped to 1 s, stale/duplicate seq ignored, 500 ms
  watchdog, `set_jam` (decays speed `*=0.5`, position frozen). Pure C,
  no QNX headers.
- **Device vectors:** `BELT_APPLY/BELT_JAM/BELT_TICK` lines in
  `device_vector.c` (additive; pose lines unchanged).
- **genesis_device belt mode:** `argv[1] == "belt"` selects belt
  kinematics (startup banner pins the mode; pose path untouched).
  Devstate reply maps x=position, v=speed; APPLY audit keeps
  `from_pid=` plus `belt_pos=`.
- **faultinject `probe estop`:** one nominal command with
  `estop_engaged=1`, prints the verdict line. Additive; the 9 checks
  stay byte-identical in behavior.
- **Matrix 8 -> 10** (`scripts/qnx_target.py`):
  - `conv_chain`: conv guard + belt device + controller(50); asserts
    belt moved (`dev_x > 0.2`), `APPLIES >= 20`, `NONGUARD == 0`,
    `fwd_fail == 0` — the conveyor twin of `device_chain`.
  - `estop_target`: guard + status; `probe estop` must print
    `decision=DENY reason=ESTOP` and status must show `state=3` with
    `last_reason=ESTOP`.

## Contracts

- No v1 codegen/template change (frozen); no new binary: belt is an
  argv-selected mode of `genesis_device`, like `genesis_status` takes a
  node path and the controller takes a count.
- Stage rebuild from current sources (guard carries estop now); `put`
  then `verify` in one target session; per-step transcripts kept.
- Host tests: belt vector contract (integrate, stale-seq, dt clamp,
  watchdog, jam decay/freeze/no-creep), parser checks for the two new
  steps on synthetic bodies (the on-target run remains the proof).

## Self-review

- Consistent: same matrix idioms as `device_chain`/`limits_differ`

- Scope: belt chain first, estop probe second; no HAM, no Studio, no
